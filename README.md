# 👨‍🍳 Chef's Ledger

**Chef's Ledger** is a sleek, responsive recipe discovery dashboard. It allows culinary enthusiasts to search through thousands of professional recipes and save them to a personal, persistent "Ledger" for future reference.

## 🌟 Key Features

* **Real-time Recipe Discovery**: Integrated with the Spoonacular API to provide instant search results for any dish or ingredient.
* **Persistent Recipe Ledger**: Save your favorite finds to a dedicated sidebar. Your ledger stays saved even if you refresh the page, thanks to `localStorage` integration.
* **Intuitive UI/UX**: Features a responsive grid layout for search results and a "sticky" sidebar for easy ledger management.
* **Smart Filtering**: Advanced logic ensures no duplicate recipes enter your ledger, and a one-click "Remove" feature keeps your list tidy.

## 🛠️ Built With

* **React 18** (Vite) - For a lightning-fast development experience.
* **TypeScript** - Ensuring robust, type-safe code.
* **Tailwind CSS** - For modern, utility-first styling and responsive design.
